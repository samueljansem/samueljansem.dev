## About

django-blocks is inspired by [shadcn/ui](https://ui.shadcn.com/), instead of installing a package, you copy production-ready Django apps directly into your project. You own the code and can customize it however you want.

## Features

- Production-ready Django apps
- Copy and own the code
- Fully customizable
- No dependency lock-in
